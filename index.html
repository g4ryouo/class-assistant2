連線設定

建議：中繼站（Cloudflare Worker）。Claude key 存在你的 Worker 裡，這個網頁只連中繼站，所以不受組織的 CORS 限制，也不用把 key 放進瀏覽器。部署步驟見倉庫的 README。

或者（組織允許瀏覽器直連時）直接使用 API key；只存在這個瀏覽器，只傳給 api.anthropic.com。共用電腦請不要儲存。
